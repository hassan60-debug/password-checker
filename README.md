# 🔑 Password Strength Checker

A Python tool that analyzes password strength and provides actionable security improvement suggestions.

## Features
- Checks length, uppercase, lowercase, numbers, special characters
- Detects common weak passwords
- Gives score out of 6
- Provides improvement suggestions

## Usage
```bash
python password-checker.py
```

## Example Output
Password : **********
Score : 6/6
Strength : ✅ STRONG

## Technologies
- Python
- Regex (re module)
- Cybersecurity Concepts
